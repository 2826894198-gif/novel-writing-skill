# 中文长篇逐章写作 Skill

版本：0.4.0（骨架开书、冲突兑现与助手交接）

用于从骨架规划中文长篇、试写获准开篇，以及已有连载的续写、修订与连续性维护。把故事吸引力、分书表达、角色知情、逐章审查与版本恢复接成可执行流程。

## 目录与使用

- `skills/serial-fiction-writing/SKILL.md`：技能入口
- `skills/serial-fiction-writing/references/`：按需读取的项目接入、事实、场景、审稿与恢复指导
- `skills/serial-fiction-writing/assets/templates/`：复制到作品项目中填写的空白模板
- `skills/serial-fiction-writing/sources.md`：公开方法来源、原创改编及版权边界
- `tests/validation-summary.md`：本轮实际验证内容与未验证范围

将完整技能目录提供给支持 SKILL.md 的助手，先接入作品的当前有效版本，再按入口逐章执行。仓库同步不代表已在某台设备安装或启用技能。

新书从“骨架到开篇”入口开始；已有书保留原资料结构。给 dots 使用时，同时提供作品侧当前入口，参见 [助手交接](skills/serial-fiction-writing/references/assistant-handoff.md)。无需将整个仓库和全部参考反复塞进每章输入。

作品事实、正文、私人人物表、实际授权和平台状态放在独立项目中，不回填到这个通用仓库。使用时只载入当前作品的相关资料，不能混入另一部作品。

## 核心取舍

- 已发生事实、人物误信、未来计划分开；事实的故事生效时点、人物获知时点与正文揭示位置分开
- 候选稿和事实增量一起检查，满足项目采纳标准后提交，并核验正文、索引、事实一致
- 写成的正文可能偏离写前计划；据实际正文更新记录，不能把已发生的告知仍当作待发生
- 修改旧章回查实际依赖；下一章未写只能标待验证
- 各作品保留自己的写法，不设通用笑点配额、句式禁令或 AI 检测分门槛
- 安装、账号连接、远端上传与平台发布不由写作技能自动授权

## 当前证据边界

0.4.0 将阅读效果与事实无错分开，新增开篇规划和有针对性的冲突诊断；修正把某类温和表达推广到全部题材、用局部小修保护失效场景的风险。它仍是辅助创作方法，不是签约保证。新版实际测试见 [验证说明](tests/validation-summary.md)，不把旧版试跑追认为新版效果证据。

历史版本曾完成结构检查、八类协议情境审读，以及两部不同类型作品各一章的实际续写与局部修订。0.4.0 另完成两项新任务的隔离短写试跑：一项利益谈判，一项温暖日常。后者保留了轻松回报；前者虽达成可执行安排，对方接受原价的动机仍值得补强。两项只支持流程可执行、题材未被强行同化，不能证明文学效果优于旧版、长篇稳定或商业收益。

该目录不包含第三方付费材料、小说文本或代码复制。未附开源许可证；私有保存不等于授权公开分发。第三方方法的版权边界见 sources.md。

## 0.2.0补强

## 0.2.1 缺陷回归补丁
根据后续实际写作中发现的漏检，补充按需缺陷回归入口及可计算时间跨度的运算证据。区分检查规则缺失和既有检查漏执行，保留中性边界案例，不以一次错误推断长期高频。后续一批八章已经用于检查实际错误，但不构成长期稳定性或收益验证。

## 0.3.0 情绪目标与按需技巧
新增14张原创技巧卡与公开来源说明、反向设计情绪目标和事件代价、双轮外部模型审读。技巧按具体缺口调用，不设数量或强度分数；允许试验后保留原文。一次隔离段落前瞻试写发现原段已含目标机制，添加对白反有重复风险；据此明确隔离实验与正式整章验收边界。完成21个技能文件、41处相对链接、3个JSON模板及基础结构检查。未证明整章长期稳定、真人情绪强度或商业表现。

## 0.3.1 针对性回归
补绝对断言和新公历锚点的回读入口，加入只标候选措辞、不判错的可选脚本；把创作简报与完整核验分开，避免审稿语言变成人物对白。隔离新任务独立试跑修正三处有证据的冲突，同时保留合理新事件和亲密动作；这是单例行为观察，非长期或商业效果证明。
